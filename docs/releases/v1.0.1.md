# tikray v1.0.1 — Fast MikroTik One-Paste Install & Pre-Packaged Signed Installers

**tikray v1.0.1** makes installing **tikray** on any supported MikroTik RouterOS v7 router effortless — **no Go toolchain, no git clone, and no PC required**. Every GitHub Release now ships signed container archives, pre-packaged chunk-verified installers for all supported RouterOS v7 release lines, and an auto-detecting `bootstrap.rsc`.

---

## Fast Install Directly on MikroTik

Prerequisites: RouterOS `7.23.8+`, `7.24.6+`, or `7.25.x`, matching `container` package, `/system/device-mode/update container=yes`, `/ip/dns/set allow-remote-requests=yes`, and a mounted ext4 disk (`disk1` by default — check `/disk/print`).

Open **WinBox → New Terminal** (or RouterOS SSH) and paste:

```routeros
/tool/fetch url="https://github.com/Arman2122/tikray/releases/latest/download/bootstrap.rsc" dst-path="tikray-bootstrap.rsc"
/import file-name="tikray-bootstrap.rsc"
```

Once installation finishes, retrieve your one-time first-run setup code and open the printed HTTPS URL:

```routeros
/container/shell [find comment="tikray:tikray"] cmd="tikray setup-code"
```

## What's New in v1.0.1

- **Auto-Detecting MikroTik Bootstrap (`bootstrap.rsc`)**: Validates architecture (`arm64` / `x86_64` CHR), RouterOS version, `container` package, `device-mode`, ext4 disk, and router DNS before downloading anything; fetches the matching signed `.tar` archives and `install-<line>-<arch>.rsc` straight onto your ext4 disk (`disk1`), then runs the full 16 KiB SHA-512 verified installer.
- **Pre-Packaged Signed Installers in Every Release**: Publishes `install-7.25.1-{arm64,amd64}.rsc`, `install-7.24.6-{arm64,amd64}.rsc`, `install-7.23.8-{arm64,amd64}.rsc`, `bootstrap.rsc`, `uninstall.rsc`, `*.tar`, `*.tar.sig`, `publisher.pub`, `SHA256SUMS`, and SPDX SBOM automatically on every tag.
- **Documentation & CLI Fixes**: Corrected control-container shell examples (`comment="tikray:tikray"`) across `README.md` and Wiki guides, and added fast 2-line MikroTik uninstall commands.
- **Image Inspection & CHR Stability**: Removed per-16 KiB chunk heap allocations in `internal/imagearchive` and hardened RouterOS CHR watchdog/update acceptance checks against LTS conntrack churn, SSH login bursts, and trailing console notices.

## Release Artifacts & Verification

| Artifact | Purpose |
|---|---|
| `bootstrap.rsc` | Auto-detecting 2-line RouterOS v7 fast installer helper pinned to `v1.0.1` |
| `install-7.25.1-{arm64,amd64}.rsc` | Verified installer for RouterOS `7.25.x` (stable) |
| `install-7.24.6-{arm64,amd64}.rsc` | Verified installer for RouterOS `7.24.6+` (long-term) |
| `install-7.23.8-{arm64,amd64}.rsc` | Verified installer for RouterOS `7.23.8+` (legacy long-term) |
| `tikray-{arm64,amd64}.tar` (+ `.sig`) | Control-plane container archive (`busybox:1.37.0-musl` + static Go + embedded Web UI) |
| `tikray-runner-{arm64,amd64}.tar` (+ `.sig`) | Minimal `FROM scratch` data-plane supervisor container archive |
| `uninstall.rsc` | Clean `keep` (default) / `purge` RouterOS uninstaller |
| `publisher.pub` & `SHA256SUMS` | ECDSA P-256 verification key & SHA-256 digests of all release assets |
| `tikray-v1.0.1.spdx.json` | Software Bill of Materials (SPDX JSON) |

```sh
sha256sum -c SHA256SUMS
cosign verify-blob --key publisher.pub --signature tikray-arm64.tar.sig --offline --insecure-ignore-tlog tikray-arm64.tar
cosign verify-blob --key publisher.pub --signature tikray-runner-arm64.tar.sig --offline --insecure-ignore-tlog tikray-runner-arm64.tar
```
