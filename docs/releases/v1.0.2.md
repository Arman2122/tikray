# tikray v1.0.2 — Default `iran` Geo Profile Powered by IR-Geo-DB

**tikray v1.0.2** switches the built-in `iran` geo profile to **[Arman2122/IR-Geo-DB](https://github.com/Arman2122/IR-Geo-DB)** and makes `iran` the default geo profile across the CLI, HTTPS API, and embedded Web UI.

---

## Fast Install Directly on MikroTik

Open **WinBox → New Terminal** (or RouterOS SSH) and paste:

```routeros
/tool/fetch url="https://github.com/Arman2122/tikray/releases/latest/download/bootstrap.rsc" dst-path="tikray-bootstrap.rsc"
/import file-name="tikray-bootstrap.rsc"
```

---

## What's Changed in v1.0.2

- **`Arman2122/IR-Geo-DB` Integration (`iran` profile)**:
  - Pulls daily-rebuilt `geoip.dat` and `geosite.dat` from `Arman2122/IR-Geo-DB` (`vYYYY.MM.DD` tags, verified against each release's `SHA256SUMS` manifest).
  - Routes domestic traffic via `geosite:ir` and `geoip:ir` (with RIPE-corrected Iranian IPv4 prefixes synced automatically into RouterOS's domestic address-list), while making `geosite:ads`, `geosite:malware`, `geosite:phishing`, `geosite:cryptominers`, and `geoip:malware` available for custom routing rules.
- **`iran` as Default Geo Profile**:
  - `tikray geo update latest` (without `--profile`), `POST /v1/geo/update {"version":"latest"}`, `GET /v1/geo`, and the embedded Web UI `Updates` view now default to `iran` automatically when no other profile is configured or active.
- **Pre-Packaged Signed Installers**: Ships `bootstrap.rsc`, `install-{7.25.1,7.24.6,7.23.8}-{arm64,amd64}.rsc`, `uninstall.rsc`, multi-arch `.tar` archives + `.tar.sig` signatures, `publisher.pub`, `SHA256SUMS`, and SPDX SBOM.
