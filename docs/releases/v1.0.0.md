# tikray v1.0.0 — First Production Release

**tikray v1.0.0** is the first stable open-source release bringing hardened, self-healing **[xray-core](https://github.com/XTLS/Xray-core)** routing natively to **MikroTik RouterOS v7** containers — with an embedded offline-first Web UI, zero-downtime hot server reloads, deadline-backed trial rollbacks, and full air-gapped network support.

---

## Highlights

### Native MikroTik RouterOS v7 Support (`7.23.8` – `7.25.1` + Forward-Compatible `7.26+`)
- **Lab-verified tracks**: **`7.25.1`** (stable, `7.25.x` patches), **`7.24.6`** (long-term, `7.24.x` patches), and **`7.23.8`** (legacy long-term, `7.23.x` patches).
- **Future-proof `7.26+` forward-compatibility**: Canonical future stable/long-term v7 releases map cleanly onto the modern `7.23+` adapter profile with a non-blocking `untested` indicator in `/v1/status` and the Web UI, while pre-releases (`beta`/`rc`/`testing`/`development`), `.0` patches, v6/v8, and pre-`7.23.8` builds remain strictly refused.
- **Scoped, readback-verified native API-SSL reconciler**: Certificate-pinned session, generation-bound mutations, automatic drift repair (`/listen` + 30s sweep), IPv6 leak guard, existing source-NAT safety, and native RouterOS **`tikray-watchdog`** + **`tikray-emergency-off`** (works even with both containers stopped).
- **RouterOS DHCP integration**: Live bound LAN lease discovery (`GET /v1/routeros/leases`) and one-click static DHCP lease conversion (`POST /v1/routeros/leases/static` / `tikray device make-static <ip>`).

### Embedded Svelte 5 Web UI (57 KB Gzipped · 100% Offline)
- Compiled directly into the `tikray` Go binary (`go:embed`) with **zero external fonts, CDNs, or network beacons** and automatic Dark / Light themes.
- **Live Observability**: Pure-SVG real-time Download/Upload throughput chart, interactive 4-stage Data-Path Topology (`LAN → RouterOS v7 → xray-core → Active Exit`), Proxy-vs-Direct traffic split bar, server latency bars, and auto-polling redacted Live Events with `boot_id` restart detection.
- **Fast Operator UX**: Global **`Ctrl+K` / `⌘K` Command Palette** for instant navigation, actions, and server pinning, plus a **client-side Share-Link Inspector** displaying protocol/transport/security capability badges (`REALITY`, `XTLS-Vision`, `XHTTP+Extra`, `ML-DSA-65`, `ECH`, `Pinned Cert`, `allowInsecure` warnings) before submission without echoing credentials.

### Modern `xray-core` 26.x Support (`v26.1.18` – `v26.11.9`)
- **VLESS** (`xtls-rprx-vision`, Post-Quantum VLESS `encryption` pass-through), **REALITY** (including **Post-Quantum ML-DSA-65 `pqv` → `mldsa65Verify`**), **XHTTP / SplitHTTP** (including validated **`extra` JSON** for XMUX, `downloadSettings`, `noGRPCHeader`, and padding — 16 KiB cap, zero secret echo, nested `allowInsecure` blocked), **TLS + ECH** (`ech` → `echConfigList`), certificate pinning (`pcs`, `vcn`), **VMess**, **Trojan**, **Shadowsocks & SS-2022**, plus raw JSON outbound import.
- **Zero-downtime hot server changes** via `xray api` (`rmo`/`ado` + `/v1/adopt`) without restarting `xray-core` or dropping active LAN sessions.
- **Four independent update lifecycles**: update `xray-core`, Geo bundles (`iran`, `v2fly`, `loyalsoldier`, `custom`), `tikray` (blue/green, zero traffic drop), and `tikray-runner` independently — with cryptographic verification and automatic rollback on failure.

### Security, Backups & Router Performance
- **Passphrase-Encrypted Backup & Restore (`tikray-backup-v1`)**: Full state (including server credentials and subscription URLs) sealed with **Argon2id (`19 MiB, t=2, p=1`, bounded concurrency) + AES-256-GCM**, preserving managed bridge subnets across restores.
- **Offline & Censored-Network Inbox**: Browser and API uploads (`POST /v1/inbox/core/{name}`, `POST /v1/inbox/geo/{profile}/{version}/{name}`) with symlink-safe `O_NOFOLLOW` atomic staging, plus proxy-fallback and custom mirror support.
- **Tuned Router Memory Budgets**: Default `GOMEMLIMIT=48MiB` (`tikray`) and `GOMEMLIMIT=24MiB` (`tikray-runner`) alongside `XRAY_GOMEMLIMIT=128MiB` (`xray-core`) — sized for 256–512 MB ARM64 MikroTik routers (hAP ax², hAP ax³, RB5009, L009, Chateau, CCR2xxx, CHR).
- **Zero-Secret Redaction**: Share links, server UUIDs/passwords, subscription URLs, passwords, setup codes, API tokens, session IDs, CSRF tokens, backup passphrases, and RouterOS credentials never leak into API views, logs, events, history files, or error messages.

## Release Artifacts & Verification

Every tagged release publishes RouterOS-compatible classic Docker image tarballs, multi-arch GHCR images, a self-contained uninstaller, checksums, an SPDX SBOM, and (when release signing is enabled) Cosign signatures and pre-packaged RouterOS installers:

| Artifact | Purpose |
|---|---|
| `tikray-arm64.tar` / `tikray-amd64.tar` | Control-plane container archive for RouterOS (`busybox:1.37.0-musl` + static Go + embedded UI) |
| `tikray-runner-arm64.tar` / `tikray-runner-amd64.tar` | Minimal `FROM scratch` data-plane supervisor container archive |
| `install-7.25.1-{arm64,amd64}.rsc` / `install-7.24.6-{arm64,amd64}.rsc` | Packaged RouterOS installers with 16 KiB chunked SHA-512 verification (when signed) |
| `uninstall.rsc` | Clean `keep` (default) / `purge` RouterOS uninstaller |
| `*.tar.sig` + `publisher.pub` | Detached Cosign signatures & publisher public key (when signed) |
| `SHA256SUMS` | SHA-256 digests of all published archives and scripts |
| `tikray-v1.0.0.spdx.json` | Software Bill of Materials (SPDX JSON) |

### Verify Checksums & Signatures

```sh
# 1. Verify SHA-256 digests
sha256sum -c SHA256SUMS

# 2. Verify Cosign detached signatures (when publisher.pub & .sig files are present)
cosign verify-blob --key publisher.pub --signature tikray-arm64.tar.sig tikray-arm64.tar
cosign verify-blob --key publisher.pub --signature tikray-runner-arm64.tar.sig tikray-runner-arm64.tar
```

### Multi-Arch GHCR Container Images

```sh
ghcr.io/arman2122/tikray:v1.0.0-arm64
ghcr.io/arman2122/tikray:v1.0.0-amd64
ghcr.io/arman2122/tikray-runner:v1.0.0-arm64
ghcr.io/arman2122/tikray-runner:v1.0.0-amd64
```

## Quick Install

1. Follow the prerequisites (RouterOS `container` package, `device-mode`, ext4 `disk1`) in the [**Installation Guide**](../wiki/Installation-Guide.md).
2. Import your verified installer (online from a non-redirecting HTTPS host, or offline via `disk1/tikray/images/`):
   ```routeros
   # Offline example:
   :global tikrayCore "26.11.9"; :global tikrayOffline true; /import file-name=install-7.25.1-arm64.rsc
   ```
3. Retrieve your one-time first-run setup code and open the embedded Web UI:
   ```routeros
   /container/shell [find comment="tikray:ctl"] cmd="tikray setup-code"
   ```
